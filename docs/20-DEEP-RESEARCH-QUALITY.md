# Deep Research 证据质量与状态边界

本页为可公开的技术说明，替代包含外部资料原句的历史排查记录；原始记录保存在本地私有审查备份，不随快照分发。

## 证据归属和问题覆盖

相关材料可以保留为背景；只有明确归属于研究对象的技术主体—行为片段才计入子问题覆盖。比较名称、其他框架的能力、否定、模糊代词和未明确主体不默认覆盖。每个覆盖保存 locatable quote / capabilities，报告节点收到实际有界片段与问题—证据映射。

这是一组保守规则，不是完整自然语言语义解析；复杂表达可能漏判，宁可保留缺口。能力描述不能直接回答“局限/评估”等问题，不用第三次模型调用做覆盖判断。

## 报告与引用

模型先选证据与逐字引文，再提出各自独立的候选结论。后端逐条检查 E 编号、原文匹配、标题材料限制和数字约束。一个候选失败不丢弃其他有效候选；保留固定原因码和有界候选诊断。引用匹配只是可追溯性检查，不是独立事实认证。

completed 要有有效核心结论、足够问题覆盖且无阻断错误；有材料但结论/覆盖不足为 partial。必要报告生成失败或无法形成可用结果为 failed，不能凭 HTTP 200 宣布成功。

GitHub 限流后本任务不再请求该来源，不密集重试，其他来源证据保留；来源级警告单独展示，不强制把可选来源失败当工作流失败。
