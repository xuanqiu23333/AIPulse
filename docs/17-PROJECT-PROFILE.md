# AIPulse 项目介绍（基于已验证事实）

## 定位

个人本地 AI 情报工作台：将分散的开源发布、论文与社区新闻归并为可查询记录，再提供中文摘要、日报及带证据的多步骤研究。用途是展示数据接入、异步后端、Agent 编排和 Web 产品闭环，不冒充线上商业服务。

## 可用于简历的项目描述

在冻结的 Local Deep Researcher MIT 基线之上，设计并实现 AIPulse 业务模块和 Vue 3 工作台：接入 GitHub Releases、arXiv、Hacker News，使用 SQLAlchemy AsyncSession + MySQL 唯一约束 / UPSERT 完成标准化、去重归并与幂等入库；建立独立的重要性评分和 AI 相关性筛选，采用 Alembic 分阶段迁移及专用迁移账号保护真实开发数据。

实现 DeepSeek 统一异步 Gateway，使用 JSON + Pydantic 校验、有限 Token / 超时 / 调用次数，保存实际 usage 并区分失败调用的未知用量；摘要按内容指纹、模型和 Prompt 版本缓存，日报优先复用已存材料、每份最多一次调用，模型等待期间释放数据库事务。

使用真实 LangGraph StateGraph 编排规划、检索、证据评估、缺口识别、条件补充、报告合成、引用校验和结果持久化；约束为最多两次模型、三轮检索、18 条证据和 360 秒，持久化任务、证据与节点日志，前端呈现活动/失败/取消终态并按证据编号定位引用。实现本机访问、默认关闭付费开关、二次确认、重复提交保护及外部输入边界。

以上是本项目新增实现范围；**不是声称独立开发 LangGraph、DeepSeek 或上游源码**。对外使用“独立开发”前，应由项目本人确认自己的实际职责与所有协作者贡献。

## 已取得的真实结果

- 真实多来源采集、21 个事件与 21 条资讯入库及查询曾完成验收；不是线上用户量或吞吐指标。
- 中文摘要已真实生成、持久化与缓存命中。2026-10-17 的 v2 日报实际入选 3 个事件，生成、保存与 GET 已通过。
- 多次真实研究已执行并保存证据和节点日志，实际结果包含 failed / partial。最近一次因 report_schema_mismatch 失败，不得表述为成功报告。
- v6 报告契约、字段级脱敏诊断及语义覆盖改进已离线验证，尚缺 v6 完整成功报告的真实模型验证。参阅 [22](22-RESEARCH-REPORT-CONTRACT.md)。
