# UI V2：蓝白 AI 情报工作台

本轮于 2026-10-22 至 2026-10-23 完成前端视觉重构与只读联调。视觉以用户提供的蓝白工作台参考图为基准；新闻、日报、任务均读取实际后端，无生产 fixture 回退。

## 1. 页面与视觉

- 固定 240px Sidebar、完整 Header、浅蓝页面背景；当前路由蓝色背景与侧边标记，真实连接状态、日期、连接复查及研究快捷入口。
- 首页在 ≥1440px 使用 Sidebar / 主信息流 / 右侧情报栏。Hero 使用自绘 SVG 的 AI 芯片、News、Paper、Community 卡片；四个范围明确的统计卡、双列新闻，以及真实日报、高分新闻和最近访问任务。
- 新闻中心保留后端分页、分类、最低评分和排序；卡片补充有界详情 GET，提供发布时间和安全来源链接。评分理由独立折叠，不能冒充正文。
- 新闻详情突出原始标题与材料、AI 摘要、要点、信息局限；评分和来源置于辅助栏。缺少正文保留真实说明。
- 日报合并为连续的报告阅读面，保留日期、旧规则警告、概览、重点新闻、栏目、来源、局限和用量。
- Research 工作台统一主题输入、费用边界、二次确认、UUID 查询及真实最近任务状态；详情使用状态概览、真实节点时间线、报告和证据库。失败报告继续隐藏成功结论。
- 1024–1439px 将首页右栏移至下方；768–1023px 抽屉导航；<768px 主要内容单列，375px 统计卡 2×2。移动表单 16px 字体，主要触控区域至少 44px；支持可见焦点、减少动画和原生确认 dialog。

## 4. 数据范围与安全边界

- 已保存事件数直接使用列表 `total`；来源数仅计算首页已加载 6 条的 provider，当前真实值为 1，不能标成全库来源总量。
- 重点区从实际评分前 20 条中筛选 model/paper/tool/product，最多 5 条，明确未另做 AI 主题核验。最新区仍遵循真实 latest 排序，因此可能包含上游 HN 非 AI 内容。
- 后端没有日报列表 API。首页只检查今天及当前新闻创建/更新日期中最近的最多 3 个日期；不保证发现所有历史日报，也不把未找到解释为全库不存在。读取失败和未检查日期分别显示。
- 本浏览器历史最多保存 10 个任务 ID；首页最多 GET 1 个，工作台最多 GET 3 个，不冒充全库任务列表，不轮询模拟进度。
- 列表无正文/封面字段。详情有 `summary` 才展示已存摘录；缺失时明确说明。来源图形只是来源标识，没有用随机图片替代真实封面。
- 所有 POST 继续二次确认、有界等待、提交禁用且不自动重试。仅 GET 做真实联调，模型调用、研究创建、摘要/日报生成和数据库写入均未执行。
- 本轮本地服务六个开关显式设为 0。保留 loopback、Origin 防护和后端费用限制；前端不读取服务端 .env，不接收 API Key。

## 5. 安全启动与检查命令

先停止同端口旧进程，再分别打开两个 PowerShell。数据库沿用现有 0004，UI V2 无迁移步骤。

终端 A：

```powershell
Set-Location D:\Projects\AIPulse
$env:PYTHONPATH = 'src'
$env:AIPULSE_ENABLE_MANUAL_COLLECTION = '0'
$env:AIPULSE_ENABLE_SCHEDULED_COLLECTION = '0'
$env:AIPULSE_ENABLE_AI_SUMMARY = '0'
$env:AIPULSE_ENABLE_DAILY_BRIEF = '0'
$env:AIPULSE_ENABLE_RESEARCH = '0'
$env:AIPULSE_ENABLE_RESEARCH_EXTERNAL = '0'
python -B -m uvicorn aipulse.api.main:app --host 127.0.0.1 --port 8000 --workers 1 --no-proxy-headers
```

终端 B（已安装 Node/npm）：

```powershell
Set-Location D:\Projects\AIPulse\frontend
# 首次安装依赖时执行 npm ci；当前机器依赖已经安装
npm run dev
```

当前机器没有全局 Node/npm 时，使用已存在的工具路径：

```powershell
Set-Location D:\Projects\AIPulse\frontend
$uiNodeDir = 'C:\Users\<WindowsUser>\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin'
$uiNode = Join-Path $uiNodeDir 'node.exe'
$uiNpm = 'C:\Users\<WindowsUser>\Documents\ChatGPT\aipulse\tools\npm\package\bin\npm-cli.js'
$env:PATH = "$uiNodeDir;$env:PATH"
& $uiNode $uiNpm run dev
```

打开 `http://127.0.0.1:5173/`。真实数据页可访问 `/news/7`、`/briefs?date=2026-10-20`、`/research/10dde09d-e19e-44f5-a0ec-0148379426ed`。任务 ID 仅在文档中用于已存失败记录验收，未硬编码进产品。

离线验证命令（标准 npm；当前机器可等价使用 `& $uiNode $uiNpm ...`）：

```powershell
npm run typecheck
npm test
npm run build
```

生产 `dist/` 使用相对 `/api`。实际部署需同源反向代理 `/api` 到 FastAPI，并将前端路由回退到 index.html；Vite preview 不提供生产 API 代理。更多环境和故障处理见 [本地部署](15-LOCAL-DEPLOYMENT.md)。

## 8. 当前局限

没有全站搜索、日报列表或研究任务列表接口，因此未制作假搜索或假列表。首页日报查找有界，新闻材料受实际接口字段限制；真实最新 HN 新闻并不全属于 AI。缺少已成功的真实研究报告，本轮只能验证既有失败任务及离线有效报告引用测试。UI V2 不对这些后端业务边界做扩展。
