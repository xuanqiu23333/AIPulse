## 可复现性

- Python >=3.11，依赖由 uv.lock 锁定；Python 3.11.17 为实际检查环境。首次部署见 [15](15-LOCAL-DEPLOYMENT.md)。
- 空库入口固定逐阶段执行 0001–0004，不修改迁移文件。四份文件都按既有审核 SHA-256 校验；在同一连接验证空库、专用迁移账号、Schema、权限与备份，非空库拒绝初始化。每阶段校验后才继续，失败不自动重试或清理。
- 0002/0003 现有库继续使用各自的受保护增量入口。开发库与测试库不能互换；历史测试库维护入口不是首次部署指令。
- 不依赖原开发库的新闻或摘要：空库运行会显示空状态，写入、采集、定时和付费功能默认关闭。
- 前端源码及 package-lock 纳入，不分发 node_modules 或 dist。验证构建只说明当前环境可构建，不能替代真实 API 联调。

本轮仅做离线代码、Schema 契约及独立快照检查；没有真实空库迁移、干净 Conda 全量安装、模型调用、新闻采集或新研究任务。具体命令、退出码和快照 SHA-256 清单由维护者在项目外保存，不能声称已完成未执行的操作。
